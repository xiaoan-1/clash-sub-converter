# 配置组装过程

本文档详细说明 `src/converter.js` 如何将解析结果组装成完整的 Clash YAML 配置。

---

## 组装入口

**文件**：`src/converter.js`  
**函数**：`convertToClash(proxies, options)`

```js
convertToClash(proxies, options)
```

### 输入

| 参数 | 来源 | 说明 |
|------|------|------|
| `proxies` | `src/parser.js` → `parseSubscription()` | 统一代理对象数组 |
| `options.ruleOptions` | `index.js` → `parseRuleOptions()` | OpenClash 的 include/exclude 解析结果 |

### 输出

完整的 Clash YAML 字符串，直接返回给 OpenClash。

---

## 组装的 5 个部分

```
convertToClash()
    │
    ├─ ① 基础配置        硬编码默认值
    ├─ ② DNS 配置        getDefaultDNS()
    ├─ ③ proxies         直接使用 parser.js 的输出
    ├─ ④ proxy-groups    generateProxyGroups(proxies)  ← src/proxy-groups.js
    └─ ⑤ rules           generateRules(ruleOptions)    ← src/rules/rules.js
```

---

## ① 基础配置

**来源**：硬编码默认值

```js
const config = {
  'mixed-port': 7890,        // HTTP/SOCKS5 混合端口
  'allow-lan': true,         // 允许局域网连接
  'bind-address': '*',       // 监听所有网卡
  mode: 'rule',              // 规则模式
  'log-level': 'info',       // 日志级别
  'external-controller': '127.0.0.1:46011'  // 外部控制器地址
};
```

如果有 `secret` 参数，还会加上 `config.secret`。

---

## ② DNS 配置

**来源**：`getDefaultDNS()` 函数，硬编码

```js
dns = {
  enable: true,
  listen: '127.0.0.1:1053',
  ipv6: true,
  'default-nameserver': ['223.5.5.5', '119.29.29.29'],  // 国内 DNS
  'enhanced-mode': 'fake-ip',      // fake-ip 模式
  'fake-ip-range': '198.18.0.1/16',
  nameserver: [
    'tls://dot.pub',               // DNS over TLS
    'tls://dns.alidns.com',
    'https://dns.alidns.com/dns-query',  // DNS over HTTPS
    // ...
  ],
  fallback: [
    'tls://dns.google',            // 国外 DNS
    'tls://one.one.one.one',
    'https://dns.cloudflare.com/dns-query',
    // ...
  ],
  'fallback-filter': {
    geo: ['240.0.0.0/4', '0.0.0.0/32', '127.0.0.1/32']
  }
}
```

**设计思路**：
- `nameserver`：国内 DNS，用于解析国内域名
- `fallback`：国外 DNS，用于解析被污染的域名
- `fake-ip`：Clash 分配假 IP，由 Clash 自己处理 DNS 解析
- `fallback-filter`：当国内 DNS 返回的 IP 在 geo 列表中时，才使用 fallback

## ③ proxies（代理节点）

**来源**：直接使用 `parser.js` 的输出，不做任何处理

```js
config.proxies = proxies;
```

每个节点的结构参考 `docs/协议解析输出.md`。

## ④ proxy-groups（代理分组）

**来源**：`src/proxy-groups.js` → `generateProxyGroups(proxies)`

### 输入

- `proxies[]`：解析后的节点数组

### 处理流程

```
proxies[]
    │
    ├─ 遍历每个节点
    │   └─ getRegion(proxy.name)
    │       ├─ 先检查是否匹配 CN_KEYWORDS → '🇨🇳 中国大陆'
    │       └─ 再检查 REGION_KEYWORDS (22 个地区)
    │
    ├─ 按地区分组
    │   ├─ domesticProxies[]     国内节点
    │   └─ regionMap{}           地区 → 节点名数组
    │       ├─ '🇭🇰 香港': ['香港节点01', 'HK-02', ...]
    │       ├─ '🇯🇵 日本': ['东京节点', 'JP-01', ...]
    │       ├─ '🇺🇸 美国': ['US-01', '洛杉矶', ...]
    │       └─ ...
    │
    └─ 生成分组配置
```

### 输出的分组

| 序号 | 分组名 | 类型 | 包含的节点 | 说明 |
|------|--------|------|-----------|------|
| 1 | 🚀 节点选择 | select | ♻️ 自动选择, 🇨🇳 中国大陆, 所有节点 | 主分组，手动选择 |
| 2 | ♻️ 自动选择 | url-test | 非国内节点 | 自动选最低延迟 |
| 3 | 🇨🇳 中国大陆 | select | DIRECT + 国内节点 | 国内流量直连 |
| 4 | 🇭🇰 香港 | url-test | 香港节点 | 地区自动选 |
| 5 | 🇯🇵 日本 | url-test | 日本节点 | 地区自动选 |
| ... | 其他地区 | url-test | 对应地区节点 | 22 个地区 |
| n-5 | 💬 Telegram | select | 🚀 节点选择 + 国际节点 | 服务分组 |
| n-4 | 📺 YouTube | select | 🚀 节点选择 + 国际节点 | 服务分组 |
| n-3 | 🎬 Netflix | select | 🚀 节点选择 + 国际节点 | 服务分组 |
| n-2 | 🤖 OpenAI | select | 🚀 节点选择 + 国际节点 | 服务分组 |
| n-1 | ⌨️ GitHub | select | 🚀 节点选择 + 国际节点 | 服务分组 |
| n | 🐟 漏网之鱼 | select | 🚀 节点选择 + 🇨🇳 中国大陆 + DIRECT + 所有节点 | 兜底 |

### 关键逻辑

**地区分组**：
```js
// 每个地区生成一个 url-test 分组
for (const [region, names] of Object.entries(regionMap)) {
  groups.push({
    name: region,
    type: 'url-test',
    url: 'http://www.gstatic.com/generate_204',
    interval: 300,    // 每 300 秒测速
    tolerance: 50,    // 容差 50ms
    proxies: names
  });
}
```

**服务分组**（Telegram/YouTube/Netflix...）：
```js
// 服务分组包含所有国际节点
const internationalProxies = ['🚀 节点选择', ...getInternationalProxies(regionMap)];

groups.push({
  name: '💬 Telegram',
  type: 'select',
  proxies: internationalProxies
});
```

**哔哩哔哩特殊处理**：
```js
// Bilibili 默认直连，可选港台节点
const biliProxies = ['DIRECT'];
if (regionMap['🇭🇰 香港']) biliProxies.push(...regionMap['🇭🇰 香港']);
if (regionMap['🇹🇼 台湾']) biliProxies.push(...regionMap['🇹🇼 台湾']);
```

## ⑤ rules（路由规则）

**来源**：`src/rules/rules.js` → `generateRules(ruleOptions)`

### 输入

`ruleOptions` 对象，由 `index.js` 的 `parseRuleOptions()` 生成：

```js
{
  includeTelegram: true,    // OpenClash include=(?i)telegram 匹配到
  includeOpenai: true,      // OpenClash include=(?i)openai 匹配到
  includeYoutube: false,    // 未匹配
  includeNetflix: false,
  includeDisney: false,
  includeDazn: false,
  includeBahamut: false,
  includeBilibili: false,
  includeGitHub: false,
  includeMiHoYo: false
}
```

### 处理流程

```
ruleOptions
    │
    ├─ includeTelegram: true  → getTelegramRules()   → 38 条规则
    ├─ includeOpenai: true    → getOpenAIRules()     → 11 条规则
    ├─ includeYoutube: false  → 跳过
    ├─ includeNetflix: false  → 跳过
    └─ ...
        │
        ├─ 始终包含：GEOIP,CN,🇨🇳 中国大陆
        ├─ 始终包含：LAN 直连规则
        └─ 始终包含：MATCH,🐟 漏网之鱼（兜底）
```

### 输出的规则结构

```
rules = [
  // 自定义直连
  'DOMAIN,carpetpacific.com,DIRECT',

  // GeoIP 国内直连
  'GEOIP,CN,🇨🇳 中国大陆',

  // Telegram 规则（38 条，includeTelegram=true 时）
  'DOMAIN-SUFFIX,telegram.org,💬 Telegram',
  'DOMAIN-SUFFIX,t.me,💬 Telegram',
  'IP-CIDR,91.108.4.0/22,💬 Telegram',
  // ... 更多

  // OpenAI 规则（11 条，includeOpenai=true 时）
  'DOMAIN-SUFFIX,openai.com,🤖 OpenAI',
  'DOMAIN-SUFFIX,chatgpt.com,🤖 OpenAI',
  // ... 更多

  // LAN 直连规则
  'IP-CIDR,127.0.0.0/8,DIRECT',
  'IP-CIDR,172.16.0.0/12,DIRECT',
  'IP-CIDR,192.168.0.0/16,DIRECT',
  'IP-CIDR,10.0.0.0/8,DIRECT',
```

## 最终组装

```js
const config = {
  // ① 基础配置
  'mixed-port': 7890,
  'allow-lan': true,
  'bind-address': '*',
  mode: 'rule',
  'log-level': 'info',
  'external-controller': '127.0.0.1:46011',

  // ② DNS 配置
  dns: { ... },

  // ③ 代理节点
  proxies: [ ... ],           // ← parser.js 直接传入

  // ④ 代理分组
  'proxy-groups': [ ... ],    // ← proxy-groups.js 生成

  // ⑤ 路由规则
  rules: [ ... ]              // ← rules/rules.js 生成
};

// 序列化为 YAML
return yaml.dump(config, {
  lineWidth: -1,      // 不自动换行
  noRefs: true,       // 不使用 YAML 引用
  sortKeys: false,    // 保持插入顺序
  quotingType: "'",   // 单引号
  forceQuotes: false  // 仅必要时加引号
});
```

## 数据来源汇总

| 配置部分 | 数据来源 | 是否依赖外部输入 |
|----------|----------|----------------|
| 基础配置 | 硬编码默认值 | ❌ |
| DNS 配置 | `getDefaultDNS()` 硬编码 | ❌ |
| proxies | `parser.js` → `parseSubscription()` | ✅ 依赖订阅源 |
| proxy-groups | `proxy-groups.js` → `generateProxyGroups(proxies)` | ✅ 依赖节点数据 |
| rules | `rules/rules.js` → `generateRules(ruleOptions)` | ✅ 依赖 OpenClash 的 include/exclude |
