# 配置格式说明

本文档说明本服务支持的**输入订阅格式**和**输出配置格式**。

---

## 一、输入：订阅格式

订阅源返回的内容可以是以下任意格式，服务会自动识别：

### 1. Base64 编码的订阅

最常见的格式。内容为一整段 Base64 字符串，解码后为多个节点链接，每行一个：

```
dm1lc3M6Ly97Impzb24ifQ0Kc3M6Ly97Imhvc3QifQ0KdHJvamFuOi8ve2hvc3R9
```

解码后：
```
vmess://eyJjcyI6IkpQIn0
ss://eyJob3N0IjoiZmkifQ
trojan://{host}
```

### 2. 纯文本节点链接

每行一个协议链接，支持以下 6 种协议：

| 协议 | 前缀 | 示例 |
|------|------|------|
| VMess | `vmess://` | `vmess://eyJ2IjoiMiIsInBzIjoi...` |
| Shadowsocks | `ss://` | `ss://YWVzLTI1Ni1nY206cGFzc3dvcmQ@server:8388#节点名` |
| ShadowsocksR | `ssr://` | `ssr://server:8388:protocol:method:obfs:base64pass/?params` |
| Trojan | `trojan://` | `trojan://password@server:443?security=tls#节点名` |
| VLESS | `vless://` | `vless://uuid@server:443?encryption=none#节点名` |
| Hysteria 2 | `hysteria2://` 或 `hy2://` | `hy2://password@server:443#节点名` |

### 3. Clash YAML 格式（作为输入）

如果输入已经是 Clash YAML 格式（包含 `proxies:` 字段），也能直接解析其中的节点。

---

## 二、各协议节点格式详解

### VMess

```
vmess://Base64(JSON)
```

JSON 结构：

```json
{
  "v": "2",
  "ps": "节点名称",
  "add": "server.example.com",
  "port": "443",
  "id": "uuid-xxxx-xxxx-xxxx",
  "aid": "0",
  "net": "ws",
  "type": "none",
  "host": "cdn.example.com",
  "path": "/ws",
  "tls": "tls",
  "sni": "sni.example.com"
}
```

| 字段 | 说明 | 必填 |
|------|------|------|
| `ps` | 节点名称 | 否（默认 server:port） |
| `add` | 服务器地址 | **是** |
| `port` | 端口 | **是** |
| `id` | UUID | **是** |
| `aid` | AlterID | 否（默认 0） |
| `net` | 传输层：`tcp` / `ws` / `h2` / `grpc` | 否（默认 tcp） |
| `tls` | 是否 TLS：`tls` 或空 | 否 |
| `host` | WS/H2 Host | 否 |
| `path` | WS/H2 路径 | 否 |
| `sni` | TLS SNI | 否 |

### Shadowsocks

```
ss://Base64(method:password)@server:port#节点名
```

或 SIP002 格式：
```
ss://Base64(method:password@server:port)#节点名
```

支持的加密方式：`aes-256-gcm`、`aes-128-gcm`、`chacha20-ietf-poly1305`、`rc4-md5` 等。

### ShadowsocksR

```
ssr://Base64(server:port:protocol:method:obfs:Base64pass/?params)
```

参数：`obfsparam`、`protoparam`、`remarks`、`group`。

### Trojan

```
trojan://password@server:port?security=tls&sni=xxx&type=ws&path=/ws#节点名
```

| 参数 | 说明 |
|------|------|
| `security` | `tls`（默认） |
| `sni` | TLS 服务器名称 |
| `type` | 传输层：`tcp` / `ws` |
| `path` | WS 路径 |
| `allowInsecure` | 跳过证书验证：`1` |

### VLESS

```
vless://uuid@server:port?encryption=none&type=ws&path=/ws&security=tls#节点名
```

| 参数 | 说明 |
|------|------|
| `encryption` | 加密方式（通常 `none`） |
| `security` | `tls` / `reality` |
| `type` | 传输层：`tcp` / `ws` / `grpc` |
| `sni` | TLS SNI |
| `fp` | 客户端指纹 |
| `pbk` | Reality 公钥 |
| `sid` | Reality Short ID |

### Hysteria 2

```
hysteria2://password@server:port?obfs=xxx&sni=xxx#节点名
```

或简写：
```
hy2://password@server:port#节点名
```

| 参数 | 说明 |
|------|------|
| `obfs` | 混淆类型 |
| `obfs-password` | 混淆密码 |
| `sni` | TLS SNI |
| `insecure` | 跳过证书验证：`1` |

## 三、输出：Clash YAML 配置

服务输出完整的 Clash 配置文件，结构如下：

```yaml
# 基础配置
mixed-port: 7890
allow-lan: true
bind-address: '*'
mode: rule
log-level: info
external-controller: '127.0.0.1:46011'

# DNS 配置
dns:
  enable: true
  listen: '127.0.0.1:1053'
  enhanced-mode: fake-ip
  fake-ip-range: 198.18.0.1/16
  nameserver:
    - 'tls://dns.alidns.com'
    - 'https://doh.pub/dns-query'
  fallback:
    - 'tls://dns.google'
    - 'tls://one.one.one.one'

# 代理节点（从订阅解析）
proxies:
  - name: '🇭🇰 香港 01'
    type: vmess
    server: hk1.example.com
    port: 443
    uuid: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
    alterId: 0
    cipher: auto
    udp: true
    network: ws
    ws-opts:
      path: /
      headers:
        Host: cdn.example.com

# 代理分组（自动生成）
proxy-groups:
  - name: '🚀 节点选择'
    type: select
    proxies:
      - '♻️ 自动选择'
      - '🇭🇰 香港'
      - '🇯🇵 日本'
      - '🇺🇸 美国'
      # ...

  - name: '♻️ 自动选择'
    type: url-test
    proxies:
      - '🇭🇰 香港 01'
      - '🇭🇰 香港 02'
    url: 'http://www.gstatic.com/generate_204'
    interval: 300

  - name: '🇨🇳 中国大陆'
    type: select
    proxies:
      - 'DIRECT'
      - '🚀 节点选择'

  - name: '🐟 漏网之鱼'
    type: select
    proxies:
      - '🚀 节点选择'
      - 'DIRECT'

# 分流规则（自动生成）
rules:
  - DOMAIN-SUFFIX,telegram.org,✈️ Telegram
  - DOMAIN-SUFFIX,openai.com,🤖 OpenAI
  - DOMAIN-SUFFIX,google.com,🐟 漏网之鱼
  - GEOIP,CN,🇨🇳 中国大陆
  - MATCH,🐟 漏网之鱼
```
