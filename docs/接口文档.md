## 1. 订阅转换

### POST /api/convert

完整的订阅转换接口，支持多 URL、节点过滤、关键词排除。

**请求体** `application/json`

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `urls` | `string[]` | 是* | `[]` | 订阅链接列表，支持任意协议 (http/https/vmess/ss/trojan 等) |
| `rawContent` | `string` | 否 | — | 直接传入订阅原始内容，与 `urls` 二选一 |
| `nodeFilter` | `string` | 否 | `"all"` | 节点过滤模式：`"all"` / `"hideDomestic"` / `"hideInternational"` |
| `excludeKeywords` | `string[]` | 否 | `[]` | 排除关键词列表（大小写不敏感），含任一关键词的节点将被移除。为空时使用 `config.json` 中配置的默认排除词 |
| `userAgent` | `string` | 否 | — | 拉取订阅时使用的 UA（覆盖配置中的 UA 设置），见 [GET /sub](#get-sub) 的优先级说明 |

> *当未提供 `rawContent` 时，`urls` 必填。`rawContent` 也可在 `/api/convert-file` 中使用。

**成功响应** `200`

```json
{
  "yaml": "mixed-port: 7890\nallow-lan: true\n...",
  "summary": {
    "totalNodes": 25,
    "filteredNodes": 17,
    "groups": [
      {
        "name": "🚀 节点选择",
        "type": "select",
        "proxies": ["香港01", "日本02", "新加坡03"],
        "defaultProxy": "♻️ 自动选择"
      }
    ]
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `yaml` | `string` | 完整 Clash 配置 YAML |
| `summary.totalNodes` | `number` | 原始节点总数 |
| `summary.filteredNodes` | `number` | 过滤后可用节点数 |
| `summary.groups` | `array` | 分组摘要列表 |
| `summary.groups[].name` | `string` | 分组名称 |
| `summary.groups[].type` | `string` | 分组类型：`select` / `url-test` / `system` |
| `summary.groups[].proxies` | `string[]` | 该分组下的代理名称列表 |
| `summary.groups[].defaultProxy` | `string` | 该分组的默认出口 |

`summary.groups` 末尾固定包含两个 `system` 类型条目：
- `🏠 本地路由` — 局域网 / 私有 IP / 路由器 / DDNS → DIRECT
- `🌐 GEOIP 国内直连` — GEOIP,CN → DIRECT

**错误响应**

| 状态码 | 说明 |
|--------|------|
| `400` | 缺少订阅链接 / 无法获取内容 / 无有效节点 |
| `500` | 转换异常 |

**示例**

```bash
curl -X POST http://localhost:25500/api/convert \
  -H "Content-Type: application/json" \
  -d '{
    "urls": ["https://sub.example.com/link"],
    "nodeFilter": "hideDomestic",
    "excludeKeywords": ["流量", "免费", "测试"]
  }'
```

### POST /api/convert-file

直接传入订阅原始内容进行转换，返回精简结果（仅 YAML + 节点数），适合文件上传场景。完整功能请使用 `/api/convert`。

**请求体** `application/json`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `content` | `string` | 是 | 订阅原始内容（base64 编码的 URI 列表 或 Clash YAML） |

**成功响应** `200`

```json
{
  "yaml": "mixed-port: 7890\n...",
  "count": 25
}
```

**示例**

```bash
curl -X POST http://localhost:25500/api/convert-file \
  -H "Content-Type: application/json" \
  -d '{"content": "dm1lc3M6Ly9leUoySWpw...（Base64 订阅内容）"}'
```

### POST /api/parse

仅解析订阅链接，返回节点列表（不生成配置）。

**请求体** `application/json`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `url` | `string` | 是 | 订阅链接 |
| `userAgent` | `string` | 否 | 拉取订阅时使用的 UA（覆盖配置中的 UA 设置） |

**成功响应** `200`

```json
{
  "nodes": [
    { "name": "香港 01 | 1x", "type": "vmess", "region": "🌐 其他" },
    { "name": "上海 CT", "type": "ss", "region": "🇨🇳 中国大陆" }
  ],
  "total": 2
}
```

## 2. 兼容端点

### GET /sub

兼容 subconverter 调用格式，专供 OpenClash 等客户端使用。支持多 URL（`|` 分隔）。

**查询参数**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `target` | `string` | 否 | `"clash"` | 输出格式：`"clash"` / `"surge"` |
| `url` | `string` | 是 | — | 订阅链接，多个用 `\|` 分隔 |
| `include` | `string` | 否 | — | 指定启用的规则（逗号分隔） |
| `exclude` | `string` | 否 | — | 指定禁用的规则（逗号分隔） |
| `emoji` | `string` | 否 | — | 是否保留 emoji |
| `udp` | `string` | 否 | — | 是否启用 UDP |
| `config` | `string` | 否 | — | 外部配置模板 URL |
| `ua` | `string` | 否 | — | 拉取订阅时使用的 User-Agent（覆盖配置中的 UA 设置） |

**拉取 UA 的取值优先级**

1. `?ua=` 查询参数
2. 配置中的 `fetch.userAgent`（见 [GET /api/config](#get-apiconfig)），若为 `custom` 则用 `fetch.customUserAgent`
3. 默认：`auto` 模式 —— 调用方是**已知代理客户端**时透传其 `User-Agent`；其余（浏览器、`curl`、`node`、`python-requests` 等）一律回退到 `clash-verge/v2.0.0`，避免把非客户端 UA 转发给机场

> 机场会校验拉取订阅的客户端标识。若与你的实际客户端不一致，可能被判定为「非本人操作 / 订阅地址已泄露」而作废订阅地址。

**转发的订阅元信息响应头**

机场把订阅的流量、到期时间等信息放在**响应头**里，客户端（Clash Verge / ClashX / Clash for Windows 等）靠它们展示订阅详情。转换器会原样转发：

| 响应头 | 说明 |
|--------|------|
| `subscription-userinfo` | `upload` / `download` / `total`（字节）与 `expire`（Unix 秒）。兼容 `x-amz-meta-subscription-userinfo` 这类带前缀的变体 |
| `profile-web-page-url` | 机场官网 / 用户中心地址（仅接受 `http(s)`） |
| `profile-update-interval` | 客户端自动更新间隔（小时），会被钳制到 1~720 |
| `Content-Disposition` | 订阅文件名，客户端用它作为订阅（profile）名称 |

多 URL（`|` 分隔）合并时的取值规则：

- `upload` / `download` / `total` —— **累加**
- `expire` —— 取**最早**的非 0 到期时间
- 官网地址 / 更新间隔 / 文件名 —— 取第一个非空值
- 同名节点只保留先出现的那个（mihomo 不允许代理重名）

> 若转换器终端日志显示「订阅源未下发流量 / 到期信息」，说明该机场本就不提供，与转换器无关。

**成功响应** `200` — 返回 YAML 文本 (`Content-Type: text/yaml`)，并附带上述订阅元信息响应头

**错误响应**

| 状态码 | 说明 |
|--------|------|
| `400` | 缺少 `url`；或所有订阅源均拉取失败（响应体含 `hint` 与 `failures`，便于定位是否被机场拦截）；或未解析到有效节点 |
| `500` | 转换失败 |

**示例**

```bash
curl "http://localhost:25500/sub?target=clash&url=https://sub1.example.com|https://sub2.example.com&include=openai,netflix"

# 指定拉取 UA
curl "http://localhost:25500/sub?target=clash&ua=clash-verge%2Fv2.0.0&url=https://sub.example.com/link"
```

## 3. 用户配置

### GET /api/config

获取当前用户配置。首次访问时自动返回默认配置。

**成功响应** `200`

```json
{
  "groups": [
    {
      "builtin": "select",
      "name": "🚀 节点选择",
      "type": "select",
      "defaultProxy": "♻️ 自动选择"
    },
    {
      "ruleId": "apple",
      "name": "🍎 Apple 服务",
      "type": "select",
      "enabled": true,
      "defaultProxy": "DIRECT"
    }
  ],
  "nodeFilters": {
    "hideDomestic": true,
    "hideInternational": false
  },
  "excludeKeywords": [
    "流量", "官网", "套餐", "到期", "剩余"
  ],
  "fetch": {
    "userAgent": "auto",
    "customUserAgent": ""
  }
}
```

**默认值**：若根目录的 `config.json` 不存在或缺少某项，该类目回退到 `config/default.json`；分组则逐个按 `groupOverrides` 覆盖。

| 字段 | 默认值 |
|------|--------|
| `nodeFilters.hideDomestic` | `true`（默认隐藏国内节点） |
| `nodeFilters.hideInternational` | `false` |
| `excludeKeywords` | 22 个预设关键词（流量、官网、套餐、到期、剩余、应急、免费、测试、失效、过期、活动、优惠、推荐、广告、回国、禁止、ipv6、中转、隧道、倍率、专线、-----） |
| `fetch.userAgent` | `"auto"`（透传调用方 UA，浏览器调用时回退 Clash Verge） |
| `fetch.customUserAgent` | `""`（仅 `fetch.userAgent === "custom"` 时生效） |
| `groups` | 21 个分组（4 个内置 + 17 个规则分组，见 `config/default.json`） |

---

### POST /api/config

保存用户配置。

**请求体** `application/json`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `groups` | `array` | **是** | 分组配置列表（见下方 Group 结构） |
| `nodeFilters` | `object` | 否 | 节点过滤设置 |
| `excludeKeywords` | `string[]` | 否 | 排除关键词列表 |
| `fetch` | `object` | 否 | 订阅拉取设置：`{ userAgent, customUserAgent }` |

**Group 结构**

| 字段 | 类型 | 说明 |
|------|------|------|
| `builtin` | `string` | 内置分组标识：`"select"` / `"auto"` / `"domestic"` / `"fallback"` |
| `ruleId` | `string` | 规则分组标识（对应 `config/rules/*.json` 文件名） |
| `name` | `string` | 分组显示名称 |
| `type` | `string` | 分组类型：`"select"` / `"url-test"` |
| `enabled` | `boolean` | 是否启用（内置分组和 must 分组不受影响） |
| `defaultProxy` | `string` | 默认出口节点名称 |

> `builtin` 和 `ruleId` 互斥 —— 内置分组用 `builtin`，规则分组用 `ruleId`。

**成功响应** `200`

```json
{
  "success": true,
  "config": {
    "nodeFilters": { "hideDomestic": true, "hideInternational": false },
    "excludeKeywords": ["流量", "官网"],
    "groupOverrides": { "bilibili": { "defaultProxy": "DIRECT" } }
  }
}
```

> 服务端**只持久化与 `default.json` 不同的部分**：分组差异写入 `groupOverrides`，拉取设置差异写入 `fetch`。前者为 `[]`（内容为空）时不写入。

**错误响应**

| 状态码 | 说明 |
|--------|------|
| `400` | 无效的配置格式（缺少 `groups` 数组） |
| `500` | 保存失败 |

### GET /api/user-agents

返回可用于订阅拉取的客户端 UA 预设列表，供配置界面渲染下拉框。

**成功响应** `200`

```json
{
  "presets": [
    { "id": "auto", "name": "跟随调用方（推荐）", "platform": "自动", "ua": "", "note": "透传请求 /sub 的客户端 UA；浏览器调用时回退到 Clash Verge" },
    { "id": "clash-verge", "name": "Clash Verge / Rev", "platform": "Windows · macOS · Linux", "ua": "clash-verge/v2.0.0", "note": "" },
    { "id": "openclash", "name": "OpenClash", "platform": "OpenWrt · iStoreOS", "ua": "OpenClash/v0.46.0", "note": "" },
    { "id": "custom", "name": "自定义", "platform": "手动填写", "ua": "", "note": "填入抓包得到的真实 UA 最准确" }

```

预设 ID：`auto` / `clash-verge` / `openclash` / `mihomo` / `clash-for-windows` / `clash-for-android` / `clashx` / `stash` / `shadowrocket` / `quantumultx` / `surge` / `sing-box` / `v2rayn` / `clash` / `custom`。

> 预设中的版本号只是常见取值。多数机场只做粗粒度匹配（如包含 `clash-verge`）；若校验更严，请选 `custom` 填写真实 UA。

## 4. 规则管理

### GET /api/rules

获取所有分流规则定义。

**成功响应** `200`

```json
[
  {
    "id": "apple",
    "name": "🍎 Apple 服务",
    "type": "select",
    "rules": [
      "DOMAIN-SUFFIX,apple.com",
      "DOMAIN-SUFFIX,icloud.com",
      "IP-CIDR,17.0.0.0/8"
    ]
  },
  {
    "id": "microsoft",
    "name": "Ⓜ️ 微软服务",
    "type": "select",
    "rules": [
      "DOMAIN-SUFFIX,office.com",
      "DOMAIN-KEYWORD,microsoft"
    ]
  }
]
```

> 系统规则 `common`（本地路由）不在此列表中，它始终生效且不可配置。

### POST /api/rules

创建新规则。

**请求体** `application/json`

```json
{
  "id": "myrule",
  "name": "🔧 自定义规则",
  "type": "select",
  "rules": [
    "DOMAIN-SUFFIX,example.com",
    "IP-CIDR,10.0.0.0/8"
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | `string` | 是 | 规则唯一标识（用作文件名） |
| `name` | `string` | 是 | 规则显示名称 |
| `type` | `string` | 否 | 分组类型，默认 `"select"` |
| `rules` | `string[]` | 是 | Clash 规则数组 |

**成功响应** `200` — 返回创建的规则对象

**错误响应**

| 状态码 | 说明 |
|--------|------|
| `400` | 规则已存在 / 参数无效 |

---

### PUT /api/rules/:id

更新已有规则。

**请求体** 同 POST，所有字段可选（只更新提供的字段）。

**成功响应** `200` — 返回更新后的规则对象

删除规则。

> `common`（系统规则）不可删除。

**成功响应** `200`

```json
{ "success": true }
```

## 6. 数据结构参考

### 节点过滤模式

| `nodeFilter` 值 | 效果 |
|-----------------|------|
| `"all"` | 不过滤，保留全部节点 |
| `"hideDomestic"` | 隐藏国内节点（默认行为） |
| `"hideInternational"` | 仅保留国内节点 |

> 国内节点判定：节点名称含中国大陆地区关键词（如 中国、北京、上海、广东、CN 等）。

### 默认排除关键词

共 22 个预设项：

```
流量, 官网, 套餐, 到期, 剩余, 应急, 免费, 测试, 失效, 过期,
活动, 优惠, 推荐, 广告, 回国, 禁止, ipv6, 中转, 隧道, 倍率,
专线, -----
```

> 匹配为大小写不敏感。`-----` 用于屏蔽名称为分隔线的节点。

### 支持的代理协议

| 协议 | 格式 |
|------|------|
| VMess | `vmess://base64` |
| Shadowsocks | `ss://base64` |
| ShadowsocksR | `ssr://base64` |
| Trojan | `trojan://...` |
| VLESS | `vless://...` |
| Hysteria2 | `hysteria2://...` / `hy2://...` |
| Clash YAML | 含 `proxies:` 数组的完整配置 |

### 完整 Clash 配置结构

生成的 YAML 包含以下顶层字段：

```yaml
mixed-port: 7890
allow-lan: true
bind-address: '*'
mode: rule
log-level: info
external-controller: 127.0.0.1:46011
dns: {...}             # 仅当源订阅自带 DNS 时透传（否则无此项）
proxies: [...]         # 过滤后的节点列表
proxy-groups: [...]    # 用户配置的分组 + 系统分组
rules: [...]           # 分流规则（含 GEOIP,CN,DIRECT + 本地路由）
```
