# 协议解析输出说明

本文档说明 `src/parser.js` 中六种协议解析后的统一输出结构。

所有协议解析后都会输出为统一的 proxy 对象，最终写入 Clash 配置的 `proxies` 字段。

---

## 1. VMess

**输入格式**：`vmess://Base64(JSON)`

```js
{
  name: '节点名称',            // 来自 JSON.ps，缺省则为 server:port
  type: 'vmess',
  server: 'server.example.com', // 来自 JSON.add
  port: 443,                    // 来自 JSON.port
  uuid: 'xxxxxxxx-xxxx-...',    // 来自 JSON.id
  alterId: 0,                   // 来自 JSON.aid，默认 0
  cipher: 'auto',               // 固定值
  udp: true,
  // ---- 以下字段按需出现 ----
  network: 'ws',                // JSON.net: tcp(默认) / ws / h2 / grpc / http
  'ws-opts': {
    path: '/',
    headers: { Host: '...' }
  },
  'h2-opts': {
    host: ['...'],
    path: '/'
  },
  'grpc-opts': {
    'grpc-service-name': '...'
  },
  'http-opts': {
    path: ['/'],
    method: 'POST',
    headers: { Connection: ['keep-alive'], Host: ['...'] }
  },
  tls: true,                    // JSON.tls === 'tls'
  sni: '...',                   // JSON.sni
  alpn: ['h2', 'http/1.1'],    // JSON.alpn（逗号分隔拆为数组）
  'skip-cert-verify': true      // JSON.allowInsecure === '1'
}
```

---

## 2. Shadowsocks (SS)

**输入格式**：
- SIP002：`ss://Base64(method:password)@server:port#name`
- 旧格式：`ss://Base64(method:password@server:port)#name`

```js
{
  name: '节点名称',            // # 后解码，缺省则为 server:port
  type: 'ss',
  server: 'server.example.com',
  port: 8388,
  password: 'mypassword',
  cipher: 'aes-256-gcm',       // 加密方式，缺省为 aes-256-gcm
  udp: true
}
```

---

## 3. ShadowsocksR (SSR)

**输入格式**：`ssr://Base64(server:port:protocol:method:obfs:Base64(password)/?params)`

```js
{
  name: '节点名称',            // 来自 remarks 参数，缺省则为 server:port
  type: 'ss',                  // ⚠️ 降级为 ss 类型
  server: 'server.example.com',
  port: 8388,
  password: 'mypassword',
  cipher: 'aes-256-cfb',       // 来自 SSR 的 method 字段
  udp: true
}
```

> ⚠️ Clash 不原生支持 SSR，解析时丢弃 `protocol`、`obfs` 等字段，降级为 SS 使用。

---

## 4. Trojan

**输入格式**：`trojan://password@server:port?params#name`

```js
{
  name: '节点名称',            // # 后解码，缺省则为 server:port
  type: 'trojan',
  server: 'server.example.com',
  port: 443,
  password: 'mypassword',      // 来自 URL.username
  udp: true,
  // ---- 以下字段按需出现 ----
  sni: '...',                  // sni 或 peer 参数
  'skip-cert-verify': true,    // allowInsecure=1
  network: 'ws',               // type=ws
  'ws-opts': {
    path: '/',
    headers: { Host: '...' }
  },
  'grpc-opts': {               // type=grpc
    'grpc-service-name': '...'
  }
}
```

---

## 5. VLESS

**输入格式**：`vless://uuid@server:port?params#name`

```js
{
  name: '节点名称',            // # 后解码，缺省则为 server:port
  type: 'vmess',               // ⚠️ 映射为 vmess 类型
  server: 'server.example.com',
  port: 443,
  uuid: 'xxxxxxxx-xxxx-...',   // 来自 URL.username
  alterId: 0,                  // 固定 0
  cipher: 'auto',              // 固定值
  udp: true,
  // ---- 以下字段按需出现 ----
  tls: true,                   // security=tls
  sni: '...',                  // sni 参数
  network: 'ws',               // type 参数: ws / grpc
  'ws-opts': {
    path: '/',
    headers: { Host: '...' }
  },
  'grpc-opts': {
    'grpc-service-name': '...'
  }
}
```

> ⚠️ Clash 原生不支持 VLESS，解析时映射为 `vmess` 类型（alterId=0, cipher=auto）。

---

## 6. Hysteria2

**输入格式**：`hysteria2://password@server:port?params#name` 或 `hy2://...`

```js
{
  name: '节点名称',            // # 后解码，缺省则为 server:port
  type: 'hysteria2',
  server: 'server.example.com',
  port: 443,
  password: 'mypassword',      // 来自 URL.username
  up: '20 Mbps',               // up 参数，缺省为 '20 Mbps'
  down: '50 Mbps',             // down 参数，缺省为 '50 Mbps'
  udp: true,
  // ---- 以下字段按需出现 ----
  sni: '...',                  // sni 参数
  'skip-cert-verify': true     // insecure=1
}
```

## 字段对比总览

| 字段 | VMess | SS | SSR | Trojan | VLESS | Hysteria2 |
|------|:-----:|:--:|:---:|:------:|:-----:|:---------:|
| `type` | `vmess` | `ss` | `ss` ⚠️ | `trojan` | `vmess` ⚠️ | `hysteria2` |
| `server` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `port` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `password` | — | ✅ | ✅ | ✅ | — | ✅ |
| `uuid` | ✅ | — | — | — | ✅ | — |
| `cipher` | ✅ | ✅ | ✅ | — | ✅ | — |
| `alterId` | ✅ | — | — | — | ✅ | — |
| `network` | 可选 | — | — | 可选 | 可选 | — |
| `tls` | 可选 | — | — | — | 可选 | — |
| `sni` | 可选 | — | — | 可选 | 可选 | 可选 |
| `up/down` | — | — | — | — | — | ✅ |
| `udp` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

**兼容性映射**：
- **SSR → `ss`**：Clash 不支持 SSR 协议，降级为 SS
- **VLESS → `vmess`**：Clash 不支持 VLESS 协议，通过 VMess 类型兼容（alterId=0）
