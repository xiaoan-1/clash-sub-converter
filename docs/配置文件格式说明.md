# 配置格式说明

本文档说明本服务支持的**输入订阅格式**和**输出配置格式**。

---

## 一、输入：订阅格式

订阅源返回的内容可以是以下任意格式，服务会自动识别：

### 1. Base64 编码的订阅

最常见的格式。内容为一整段 Base64 字符串，解码后为多个节点链接，每行一个：

```
dm1lc3M6Ly97Impzb24ifQ0Kc3M6Ly97Imhvc3QifQ0KdHJvamFuOi8ve2hvc3R9
```

解码后：
```
vmess://eyJjcyI6IkpQIn0
ss://eyJob3N0IjoiZmkifQ
trojan://{host}
```

### 2. 纯文本节点链接

每行一个协议链接，支持以下 14 种协议：

| 协议 | 前缀 | 示例 |
|------|------|------|
| VMess | `vmess://` | `vmess://eyJ2IjoiMiIsInBzIjoi...` |
| Shadowsocks | `ss://` | `ss://YWVzLTI1Ni1nY206cGFzc3dvcmQ@server:8388#节点名` |
| ShadowsocksR | `ssr://` | `ssr://server:8388:protocol:method:obfs:base64pass/?params` |
| Trojan | `trojan://` | `trojan://password@server:443?security=tls#节点名` |
| VLESS | `vless://` | `vless://uuid@server:443?encryption=none#节点名` |
| Hysteria 2 | `hysteria2://` 或 `hy2://` | `hy2://password@server:443#节点名` |
| Hysteria | `hysteria://` | `hysteria://auth@server:443?sni=xxx#节点名` |
| AnyTLS | `anytls://` | `anytls://password@server:443?sni=xxx#节点名` |
| TUIC | `tuic://` | `tuic://uuid:password@server:443#节点名` |
| Snell | `snell://` | `snell://psk@server:44046?version=4#节点名` |
| SOCKS5 | `socks5://` 或 `socks://` | `socks5://user:pass@server:1080#节点名` |
| HTTP | `http://` 或 `https://` | `http://user:pass@server:8080#节点名` |
| WireGuard | `wireguard://` 或 `wg://` | `wireguard://privateKey@server:51820?publicKey=xxx#节点名` |
| ShadowQUIC | `shadowquic://` | `shadowquic://user:pass@server:10443#节点名` |

### 3. Clash YAML 格式（作为输入）

如果输入已经是 Clash YAML 格式（包含 `proxies:` 字段），也能直接解析其中的节点。

## 二、各协议节点格式详解

### VMess

```
vmess://Base64(JSON)
```

JSON 结构：

```json
{
  "v": "2",
  "ps": "节点名称",
  "add": "server.example.com",
  "port": "443",
  "id": "uuid-xxxx-xxxx-xxxx",
  "aid": "0",
  "net": "ws",
  "type": "none",
  "host": "cdn.example.com",
  "path": "/ws",
  "tls": "tls",
  "sni": "sni.example.com"
}
```

| 字段 | 说明 | 必填 |
|------|------|------|
| `ps` | 节点名称 | 否（默认 server:port） |
| `add` | 服务器地址 | **是** |
| `port` | 端口 | **是** |
| `id` | UUID | **是** |
| `aid` | AlterID | 否（默认 0） |
| `net` | 传输层：`tcp` / `ws` / `h2` / `grpc` | 否（默认 tcp） |
| `tls` | 是否 TLS：`tls` 或空 | 否 |
| `host` | WS/H2 Host | 否 |
| `path` | WS/H2 路径 | 否 |
| `sni` | TLS SNI | 否 |

### Shadowsocks

```
ss://Base64(method:password)@server:port#节点名
```

或 SIP002 格式：
```
ss://Base64(method:password@server:port)#节点名
```

支持的加密方式：`aes-256-gcm`、`aes-128-gcm`、`chacha20-ietf-poly1305`、`rc4-md5` 等。

### ShadowsocksR

```
ssr://Base64(server:port:protocol:method:obfs:Base64pass/?params)
```

参数：`obfsparam`、`protoparam`、`remarks`、`group`。

### Trojan

```
trojan://password@server:port?security=tls&sni=xxx&type=ws&path=/ws#节点名
```

| 参数 | 说明 |
|------|------|
| `security` | `tls`（默认） |
| `sni` | TLS 服务器名称 |
| `type` | 传输层：`tcp` / `ws` |
| `path` | WS 路径 |
| `allowInsecure` | 跳过证书验证：`1` |

### VLESS

```
vless://uuid@server:port?encryption=none&type=ws&path=/ws&security=tls#节点名
```

| 参数 | 说明 |
|------|------|
| `encryption` | 加密方式（通常 `none`） |
| `security` | `tls` / `reality` |
| `type` | 传输层：`tcp` / `ws` / `grpc` |
| `sni` | TLS SNI |
| `fp` | 客户端指纹 |
| `pbk` | Reality 公钥 |
| `sid` | Reality Short ID |

### Hysteria 2

```
hysteria2://password@server:port?obfs=xxx&sni=xxx#节点名
```

或简写：
```
hy2://password@server:port#节点名
```

| 参数 | 说明 |
|------|------|
| `obfs` | 混淆类型 |
| `obfs-password` | 混淆密码 |
| `sni` | TLS SNI |
| `insecure` | 跳过证书验证：`1` |

### AnyTLS

```
anytls://password@server:port?sni=xxx#节点名
```

| 参数 | 说明 |
|------|------|
| `sni` | TLS SNI |
| `allowInsecure` / `insecure` | 跳过证书验证：`1` |

### TUIC

```
tuic://uuid:password@server:port?sni=xxx&alpn=h3#节点名   （V5）
tuic://token@server:port#节点名                        （V4）
```

| 参数 | 说明 |
|------|------|
| `sni` | TLS SNI |
| `alpn` | ALPN 列表，逗号分隔（如 `h3`） |
| `congestion_control` / `congestion-controller` | 拥塞控制算法（`cubic` / `new_reno` / `bbr`） |
| `udp_relay_mode` / `udp-relay-mode` | UDP 中继模式（`native` / `quic`） |
| `allowInsecure` / `insecure` | 跳过证书验证：`1` |

### Hysteria（v1）

```
hysteria://auth@server:port?sni=xxx&up=20%20Mbps&down=50%20Mbps#节点名
```

| 参数 | 说明 |
|------|------|
| `auth-str` | 密码认证 |
| `auth` | base64 的用户名:密码 |
| `obfs` | 混淆类型 |
| `protocol` | 传输协议：`udp` / `wechat-video` / `faketcp` |
| `up` / `down` | 速率（Mbps） |
| `sni` | TLS SNI |
| `insecure` | 跳过证书验证：`1` |

### Snell

```
snell://psk@server:port?version=4&obfs=http&obfs-host=bing.com#节点名
```

| 参数 | 说明 |
|------|------|
| `version` | Snell 版本（1-5） |
| `obfs` | 混淆模式（`http` / `tls`） |
| `obfs-host` | 混淆 Host |

### SOCKS5

```
socks5://user:pass@server:port?tls=1#节点名
```

| 参数 | 说明 |
|------|------|
| `tls` | 启用 TLS：`1` |
| `sni` | TLS SNI |
| `skip-cert-verify` | 跳过证书验证：`1` |

### HTTP

```
http://user:pass@server:port#节点名
https://user:pass@server:port#节点名
```

| 参数 | 说明 |
|------|------|
| `tls` | 启用 TLS：`1`（`https://` 前缀默认开启） |
| `sni` | TLS SNI |
| `skip-cert-verify` | 跳过证书验证：`1` |

### WireGuard

```
wireguard://privateKey@server:port?publicKey=xxx&ip=10.0.0.2/24#节点名
```

| 参数 | 说明 |
|------|------|
| `publicKey` | 服务端公钥（也支持 `public-key` / `pubkey`） |
| `ip` | 本机虚拟 IP（也支持 `address`） |
| `ipv6` | 本机 IPv6 |
| `mtu` | MTU 值 |
| `dns` | DNS 列表，逗号分隔 |
| `psk` | 预共享密钥 |
| `reserved` | 保留字节，逗号分隔数字 |

### ShadowQUIC

```
shadowquic://user:pass@server:port?sni=xxx&alpn=h3#节点名
```

| 参数 | 说明 |
|------|------|
| `sni` | TLS SNI |
| `alpn` | ALPN 列表，逗号分隔（默认 `h3`） |
| `quic-versions` | QUIC 版本，逗号分隔（`v1` / `v2`） |
| `congestion-controller` | 拥塞控制（`cubic` / `new_reno` / `bbr`） |

## 三、输出：Clash YAML 配置

服务输出完整的 Clash 配置文件，结构如下：

```yaml
# 基础配置
mixed-port: 7890
allow-lan: true
bind-address: '*'
mode: rule
log-level: info
external-controller: '127.0.0.1:46011'

# DNS 配置
dns:
  enable: true
  listen: '127.0.0.1:1053'
  enhanced-mode: fake-ip
  fake-ip-range: 198.18.0.1/16
  nameserver:
    - 'tls://dns.alidns.com'
    - 'https://doh.pub/dns-query'
  fallback:
    - 'tls://dns.google'
    - 'tls://one.one.one.one'

# 代理节点（从订阅解析）
proxies:
  - name: '🇭🇰 香港 01'
    type: vmess
    server: hk1.example.com
    port: 443
    uuid: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
    alterId: 0
    cipher: auto
    udp: true
    network: ws
    ws-opts:
      path: /
      headers:
        Host: cdn.example.com

# 代理分组（自动生成）
proxy-groups:
  - name: '🚀 节点选择'
    type: select
    proxies:
      - '♻️ 自动选择'
      - '🇭🇰 香港'
      - '🇯🇵 日本'
      - '🇺🇸 美国'
      # ...

  - name: '♻️ 自动选择'
    type: url-test
    proxies:
      - '🇭🇰 香港 01'
      - '🇭🇰 香港 02'
    url: 'http://www.gstatic.com/generate_204'
    interval: 300

  - name: '🇨🇳 中国大陆'
    type: select
    proxies:
      - 'DIRECT'
      - '🚀 节点选择'

  - name: '🐟 漏网之鱼'
    type: select
    proxies:
      - '🚀 节点选择'
      - 'DIRECT'

# 分流规则（自动生成）
rules:
  - DOMAIN-SUFFIX,telegram.org,✈️ Telegram
  - DOMAIN-SUFFIX,openai.com,🤖 OpenAI
  - DOMAIN-SUFFIX,google.com,🐟 漏网之鱼
  - GEOIP,CN,🇨🇳 中国大陆
  - MATCH,🐟 漏网之鱼
```

## 四、自动生成的代理分组

服务会根据**节点名称中的关键词**自动识别地区，生成对应的分组。

### 两类条目：真实分组 vs 生成器

配置页面「分组配置」里的条目分两类，语义不同：

| 类型 | 例子 | 输出里的表现 |
|------|------|-------------|
| **真实分组** | `🍎 Apple 服务`、`⌨️ GitHub`、`🇨🇳 中国大陆` | 存在同名 `proxy-group`，组内是**节点** |
| **生成器** | `🌏 地区分组` | **不存在**这个名字，它批量生成 `🇭🇰 香港` / `🇹🇼 台湾` … 等**分组** |

> `🇹🇼 台湾` 里装的是一批台湾节点（台湾1、台湾2…），它是与 `⌨️ GitHub` **平级**的独立分组，
> 而不是「🌏 地区分组」下的节点选项。`🌏 地区分组` 只是个统一开关 + 类型选择器。
>
> **引用关系（两级结构）**：`⌨️ GitHub` 这类上层分组的候选是**地区分组**，不是具体节点。
> 客户端里先选地区、再进地区组选节点，因此「GitHub 走香港」= 把 `⌨️ GitHub` 设为 `🇭🇰 香港`。
> 无法识别地区的节点归入 `🌐 其他地区` 组，保证不会有节点选不到。
>
> **输出顺序**：地区分组统一排在最后（常用分组在前，便于在客户端里查找）。

### 固定分组

| 分组 | 类型 | 说明 |
|------|------|------|
| 🚀 节点选择 | select | 必备，始终启用 |
| ♻️ 自动选择 | url-test | 必备，始终启用 |
| 🇨🇳 中国大陆 | 可配（默认 select） | 仅在有国内节点时出现 |
| 🐟 漏网之鱼 | select | 必备，始终启用 |

### 地区分组（`🌏 地区分组` 生成器）

> **默认关闭**：地区组数量随订阅里的地区数增长，节点少的订阅开着反而多出一堆
> 只有一两个节点的分组。**节点较多时建议开启**。
