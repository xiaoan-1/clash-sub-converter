# 测试样例

本目录存放订阅样例，供 `npm test`（内核校验）使用。

## mock-sub.yaml

随仓库提交的**模拟订阅**，不含任何真实服务器地址或凭据。

它刻意覆盖本项目需要处理的各类边界：

| 覆盖点 | 说明 |
|--------|------|
| **14 种协议** | vmess / ss / ssr / trojan / vless / hysteria2 / hysteria / anytls / tuic / snell / socks5 / http / wireguard / shadowquic |
| **多地区** | 港澳台、日韩新马泰越菲、印度与印尼、中东、欧洲、北美、大洋洲、非洲、南极洲 |
| **国内节点** | 验证 `🇨🇳 中国大陆` 分组与「隐藏国内」过滤 |
| **无法识别地区** | 验证 `🌐 其他地区` 兜底（节点不会被漏掉） |
| **与内置策略重名** | 名为 `DIRECT` / `REJECT` 的节点，验证自动重命名 |
| **名称含特殊字符** | 逗号、单引号、裸 `%`，验证名称解析与前端转义 |
| **广告 / 提示节点** | 「官网」「到期」「倍率」等，验证默认排除关键词 |
| **传输层变体** | TLS、WS、gRPC、Reality、hysteria2 混淆 |

## 订阅.txt（可选，不入库）

本地真实订阅。存在时 `npm test` 会额外用它跑一轮，验证真实数据下的表现；
不存在则只用 `mock-sub.yaml`。**真实订阅含机场地址与 token，绝不提交到仓库**
（`.gitignore` 已排除本目录下除 `mock-sub.yaml` 与 `README.md` 外的所有文件）。

## 用法

```bash
npm test
```

首次运行会自动下载 mihomo 内核到 `tools/`（已 gitignore），之后直接复用。
